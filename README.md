# AERO Inflatable Concepts

Static website deployed from humphreyfridt87/aero to the existing Vercel project aero-inflatable-concepts. Framework: Other. Output directory: `.`. Node.js: 22.x.

The inquiry form validates required fields and opens the visitor’s configured email app with a message addressed to humphrey@growthartistmgmt.com. The visitor must click Send in that app. The website does not send email automatically or claim delivery. If no mail app is configured, visitors can copy the displayed email address. No Resend, Turnstile, Redis, or environment variables are required.

The original design and images are retained. `/assets/*` maps to `/public/assets/*` through vercel.json.
